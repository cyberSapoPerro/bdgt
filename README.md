# Idea

Desarrollar `cli` para administrar presupuesto de forma similar a `Buckweath`.

## Framework

- `cli`: `rich`
- `backend`: `pandas`

Se guardará un `csv` con los registros. Se usará `rich` para generar visualizaciones de los gastos semanales. Se usará `pandas` para manipular los `dataframes`.

## Ideas

Crear un archivo `state.json` para guardar cositas.
